============================================================
Conda环境支持说明
============================================================

📦 Conda环境支持
---------------
脚本自动支持Conda虚拟环境，支持以下检测方式：

1. 已激活的Conda环境
   - 如果当前已激活Conda环境（CONDA_DEFAULT_ENV环境变量存在）
   - 脚本会自动使用该环境

2. 自动检测Conda安装
   - 脚本会自动查找Conda安装路径
   - 支持Anaconda和Miniconda
   - 支持从环境变量、注册表、用户目录查找

3. 手动指定Conda环境（推荐）
   - 在运行脚本前，先激活Conda环境
   - 或在脚本中指定具体的Conda环境名

🔧 使用方法
-----------

方法一：先激活Conda环境（推荐）
---------------------------
1. 打开命令提示符或PowerShell
2. 激活Conda环境：
   conda activate 环境名
3. 运行启动脚本：
   双击 start_service.bat 或 start_service_window.bat

方法二：让脚本自动检测
---------------------
1. 确保Conda已安装并添加到PATH
2. 直接运行启动脚本
3. 脚本会自动检测并尝试激活Conda环境

方法三：修改脚本指定环境名
-------------------------
如果需要指定特定的Conda环境，可以修改脚本：
1. 打开 start_service.bat 或 start_service_window.bat
2. 在激活Conda的部分，添加环境名：
   call "%CONDA_EXE%" activate 环境名

✅ 验证Conda环境
---------------
运行以下命令验证Conda环境：
   conda info
   conda env list
   echo %CONDA_DEFAULT_ENV%

⚠️ 注意事项
-----------
1. Conda环境优先于venv环境
2. 如果同时存在Conda和venv，优先使用Conda
3. 确保Conda已正确安装并初始化
4. 如果Conda未激活，脚本会尝试激活base环境
5. 开机自启动时，建议先激活Conda环境

🔍 故障排除
-----------

问题：脚本无法检测到Conda环境
解决：
1. 检查Conda是否已安装：
   conda --version
2. 检查环境变量：
   echo %CONDA_EXE%
   echo %CONDA_DEFAULT_ENV%
3. 手动激活环境后再运行脚本

问题：脚本检测到Conda但无法激活
解决：
1. 确保Conda已初始化：
   conda init cmd.exe
2. 重新打开命令提示符
3. 手动激活环境后再运行脚本

问题：开机自启动时Conda环境未激活
解决：
1. 修改 install_autostart.bat
2. 在启动脚本中添加Conda激活命令
3. 或使用Conda环境的完整Python路径

============================================================
推荐配置
============================================================

对于Conda环境，推荐使用专用脚本：

1. 使用专用Conda启动脚本（推荐）：
   - start_service_conda.bat（后台运行）
   - start_service_conda_window.bat（显示窗口）
   
   使用前先激活Conda环境：
   conda activate 环境名
   然后运行脚本

2. 或者修改脚本，在开头添加Conda激活命令：
   @echo off
   call conda activate 环境名
   ...（其他代码）

3. 配置开机自启动：
   - 修改 start_service_conda.bat，在开头添加 conda activate 环境名
   - 使用修改后的脚本配置开机自启动

============================================================
专用脚本说明
============================================================

已提供两个Conda专用脚本：

1. start_service_conda.bat
   - 后台运行服务
   - 需要先激活Conda环境
   - 如果未激活，会提示错误

2. start_service_conda_window.bat
   - 显示窗口运行服务
   - 需要先激活Conda环境
   - 如果未激活，会提示错误

使用方法：
1. 打开命令提示符
2. 激活Conda环境：conda activate 环境名
3. 运行脚本：双击 start_service_conda.bat

或者修改脚本，在开头添加：
   call conda activate 环境名

============================================================
Conda环境开机自启动配置说明
============================================================

✅ 支持开机自启动
-----------------
start_service_conda.bat 脚本已支持开机自启动！

📋 配置步骤
-----------

步骤1: 配置Conda环境名
---------------------
1. 打开 start_service_conda.bat
2. 找到以下行（大约在第8-10行）：
   set "CONDA_ENV_NAME="
   set "USE_BASE_IF_EMPTY=1"
3. 修改为您的Conda环境名，例如：
   set "CONDA_ENV_NAME=myenv"
   set "USE_BASE_IF_EMPTY=0"
4. 保存文件

步骤2: 安装开机自启动
---------------------
方法一：使用专用安装脚本（推荐）
1. 右键点击 install_autostart_conda.bat
2. 选择"以管理员身份运行"
3. 按照提示完成安装

方法二：使用通用安装脚本
1. 编辑 install_autostart.bat
2. 找到第9行：set "STARTUP_BAT=%SCRIPT_DIR%start_service.bat"
3. 修改为：set "STARTUP_BAT=%SCRIPT_DIR%start_service_conda.bat"
4. 保存后，右键以管理员身份运行

步骤3: 验证配置
--------------
1. 重启电脑或注销后重新登录
2. 等待30秒（如果使用任务计划程序）
3. 打开浏览器访问：http://localhost:8000
4. 应该能看到API信息页面

🔧 工作原理
-----------
1. 脚本启动时自动检测Conda安装路径
2. 自动激活指定的Conda环境（或base环境）
3. 使用激活后的Python运行服务
4. 支持开机自启动（通过任务计划程序或启动文件夹）

⚠️ 注意事项
-----------
1. 必须配置CONDA_ENV_NAME环境名
   - 如果留空，会尝试使用base环境
   - 建议明确指定环境名

2. Conda环境必须存在
   - 确保环境名正确
   - 可以使用 conda env list 查看所有环境

3. Conda必须正确安装
   - 脚本会自动查找Conda安装路径
   - 支持Anaconda和Miniconda
   - 支持从环境变量、注册表、用户目录查找

4. 如果自动检测失败
   - 可以手动设置CONDA_BASE变量
   - 或修改脚本中的Conda路径

🔍 故障排除
-----------

问题：开机自启动后服务未启动
解决：
1. 检查任务计划程序：
   - 按 Win+R，输入 taskschd.msc
   - 查找任务 LinkerHand_HTTP_API_Service_Dev_Conda
   - 查看上次运行结果

2. 检查Conda环境配置：
   - 确认 start_service_conda.bat 中CONDA_ENV_NAME已设置
   - 确认环境名正确

3. 手动测试脚本：
   - 双击 start_service_conda.bat
   - 查看是否有错误信息

问题：脚本无法找到Conda
解决：
1. 检查Conda是否安装：
   conda --version

2. 检查环境变量：
   echo %CONDA_EXE%

3. 手动修改脚本，指定Conda路径：
   在脚本中找到 CONDA_BASE 设置部分
   手动设置：set "CONDA_BASE=C:\path\to\Anaconda3"

问题：环境激活失败
解决：
1. 检查环境是否存在：
   conda env list

2. 手动测试激活：
   conda activate 环境名

3. 确认环境名拼写正确

📝 配置示例
-----------

示例1: 使用名为 "linkerhand" 的Conda环境
----------------------------------------
在 start_service_conda.bat 中设置：
set "CONDA_ENV_NAME=linkerhand"
set "USE_BASE_IF_EMPTY=0"

示例2: 使用base环境（如果未指定环境名）
----------------------------------------
在 start_service_conda.bat 中设置：
set "CONDA_ENV_NAME="
set "USE_BASE_IF_EMPTY=1"

示例3: 手动指定Conda安装路径
----------------------------
如果自动检测失败，可以在脚本中添加：
set "CONDA_BASE=C:\Users\YourName\Anaconda3"
